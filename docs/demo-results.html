Demo results

The completion demo (examples/mixed-harness, make demo) runs an organisation whose engineering team uses three harnesses on three model endpoints: Claude Code on Anthropic Messages (lead), Codex on OpenAI Responses (engineer, the only seat with GitHub access) and Pi on an OpenAI Chat Completions endpoint (reviewer). The team collaborates without Linear, then with work items and a pull request; work is then published to Linear through an outage; finally the Anthropic key is rotated mid-session. This page is generated by the run.

Runs against fakes and against real services are recorded separately. A fakes run uses a scripted model endpoint and a fake GitHub, so it proves the wiring (harness, model routing, tools, permissions, recovery), not model quality. A real-services run uses the real model endpoints and a real GitHub repository. In both modes Slack and Linear are the in-cluster fakes, so the Linear outage is simulated and no Slack conversation is involved; the team is driven through the representatives' fake harness.

The pull request from the real-services run is in a private demo repository, so its link in the evidence below needs access. A sanitized summary of the pull request (the demo repository is private) is public.
